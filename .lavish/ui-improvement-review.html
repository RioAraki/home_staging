改善清单

A · 空间与布局(让主游戏区更大)
A1
压缩顶栏 + 消除顶栏与 floor plan 间的黑色空隙高收益
现状顶栏下方有约 1/9 屏高的纯黑空白,白白浪费。压扁后把空间还给主游戏。
A2
floor plan 横向铺满,去掉左右黑边
现状网格只占约 62% 宽、两侧大黑边。铺满后房间/家具看得更清。
A3
主游戏区(floor plan)放大到约 60–65% 屏高你的核心诉求
这是玩家主要交互区,应是视觉主体。
A4
确立清晰三段式比例:Header ~11% / 主游戏 ~63% / 托盘 ~26%
固定结构,各机型一致,排列有秩序。
B · 区块化 & 风格统一(秩序感)
B1
每个区块给明确的容器/背景与边界
现状三块都浮在纯黑、无边框,糊成一团。各区块应一眼可分。
B2
顶栏统一成一行有序 Header
现状 房间进度(面板)+ 奖励目标(裸金字)+ 齿轮(按钮)三种风格混搭。统一面板风格、左右对齐。
B3
托盘做成明确「调色板面板」
深色圆角背景 + 标题行 + 卡片行 + 按钮列,而不是浮在黑底上的零散元素。
B4
家具卡统一尺寸(固定卡框 + 图等比居中)
现状卡片按占地大小忽大忽小(兰花宽、岛台高),很乱。统一后整齐可扫读。
C · 视觉层级 & 配色
C1
把视觉焦点让给主游戏;奖励目标降级
现状金色「奖励目标」居中最抢眼,比主游戏还突出,层级反了。
C2
定义统一配色 token,跨区块一致
背景/面板/强调金/分隔线统一,避免每块各自为政。
C3
按钮语义配色 + 清晰禁用态
放置=绿(主操作)、完成摆放=金、撤销=红;现状放置/完成都灰,语义不清。
D · 其它发现
D1
release 构建关掉 FPS 调试面板
debug 构建的 FPS 浮层会盖住托盘左侧(已实测)。release 应关闭。
D2
触控目标尺寸够大(卡片 / 按钮)
微信小游戏竖屏触屏,卡片与按钮要适合拇指点按。
D3
菜单(☰)/ 设置齿轮归入 Header 一致区
现状顶部控件分散;统一到 Header 右侧。
E · 背景与氛围(按你的反馈新增)
E1
用符合主题的背景替代纯黑,增加活力你新增
现状大面积纯黑略单调。换成"家居/装修"主题的低对比暗色氛围背景(柔和渐变 / 微纹理 / 虚化室内场景),让画面有生气。
关键约束:必须够暗、够弱,不抢主游戏 floor plan 的视觉焦点、不影响可读性;并控制微信小游戏的体积/性能(优先程序化渐变+轻纹理,慎用大图)。
E2
可选:背景随房间主题微调色调
每关/房间已有 theme 配色(如独居室偏奶白)。背景可跟着主题做轻微 tint,让不同关卡氛围有别。
设计方向:沿用游戏自身的深色 + 金色风格(非另起一套)。布局比例为示意,像素在实现时按预览微调。
