# 怡居巧匠（Verplant & Zugestellt）— 游戏规则（代码实现版）

> 本文整理自**网页版实际实现的代码**（`app/src/lib/{validation,walls,regions,scoring}.ts`、`app/src/store/game.ts`）+ 规则书 `md/RULES.zh.md`。
> 目的：作为 Cocos 移植版的**唯一规则参照**。凡代码与规则书冲突，以代码为准并在此标注。
> 末尾「§11 Cocos 简化版差异」记录我们故意改动的地方。

---

## §1 棋盘与地形

- 户型纸 = **16×16** 方格，行 1–16、列 A–P（列 c 的字母 = `String.fromCharCode(65+c)`，行 r 的数字 = `r+1`）。
- 每格有 `terrain`：`indoor`（室内可建）/ `outdoor`（室外）/ `water` / `road` / `obstacle`，外加 `feature`（tree/column/lake/…）。
- 家具**只能建在 `indoor` 格**上。`water`/`obstacle` 及带阻挡 feature（tree, column, wall_pillar, lake, low_ceiling, charred）的格子视作障碍，不可覆盖。

## §2 家具卡

- 66 张卡 = **33 个编号 × 2 个变体（A/B）**。开局每个编号**盲抽一个变体**（`chosenVariants`，随机）。
- 每张卡有若干 **option（选项）**——实测数据里**每张卡恰好 2 个 option**。当前玩家替全桌挑一个 option 画。
- 每个 option 的几何（`furniture_data.yaml`）：
  - `bbox: [行, 列]`：选项包围盒尺寸。
  - `shape`：**占用格**（家具本体，计分时 +1/格）。
  - `open_spaces`：**自由空间格**，结束时必须保持可走（空）。
  - `wall_edges`：哪几条 bbox 边**必须紧贴墙**（内墙或外墙皆可）；这段上**不能开门**。
  - `printed_markers`：卡上印的标记盘数（>0 表示要装多份）。
  - `cell_features` / `chair_count`：复合件/奖励分用的语义标签。
- **变换**：`transformOption(option, rotation, mirrored)`——先**镜像**（沿竖轴翻列）再**顺时针旋转** rotation×90°（`rotateCell`：rot1 = (c, H-1-r)）。
- **地毯（#33）特例**：默认是"薄层"，可压在别的家具下、别的家具也可压它；本身**不算占用、不计分**，只参与奖励分。场景可加 `no_furniture_on_carpet` 规则关掉这层宽容。

## §3 摆放校验（`validatePlacement`，精确）

给定 option 变换后的 shape/open_spaces 与落点 origin：

**占用格(shape)** 不能落在：
1. 出界（非 16×16 内）；
2. 非 `indoor` 地形；
3. 障碍（water/obstacle/阻挡 feature）；
4. 别人的占用格（非地毯）——例外：**新放的地毯**可压在已有家具下（默认模式）；
5. 别人的自由空间格（自由空间必须保持可走）——例外：新放地毯可压（地毯可走）；
6. 地毯占用格——仅在严格模式或"地毯压地毯"时算冲突；
7. **任何门（房间门或大门）两侧的格**（门两边必须保持可走，否则门被堵死）——地毯豁免；
8. 场景 `drawing.cells` 的"必须保持可走"格（如商店南窗带）——地毯豁免。

**自由空间格(open_spaces)** 不能落在：出界 / 非室内 / 障碍 / 别人的占用格。
- **自由空间 ↔ 自由空间 重叠：允许**（明文规则）。
- 自由空间压在地毯上：允许。

## §4 墙

- **外墙是隐式的**：`exteriorWallEdges` = 所有"室内格与非室内格之间"的边。这些边**天然算墙**，玩家无需画；`computeRegions` 也不会从室内走到室外。
- **玩家只画内墙**（把室内空间分隔成房间/走廊）。
- **连续墙拓扑**（`validateWallTopology`）：每条玩家墙的**两个端点**都必须接到**另一堵墙（玩家墙或外墙轮廓）**上。抓"悬空墙/缺口"。
  - 注意：这是必要非充分——一条从外墙到外墙的蛇形墙也能通过。
- **卡上的贴墙边**（`checkWallEdgeCompliance`）：option 的 `wall_edges` 指定的那些格边必须有墙（玩家墙**或外墙**都算），且**这段不能开门**。不满足 → 该家具**不计分**。

## §5 房间、区域、走廊

- **区域(region)** = 一片"不跨墙就能互相走到"的连通**室内格**（`computeRegions`，4 邻接，墙/门都阻挡）。室外不属于任何区域。
- **房间 → 区域**：`assignRoomsToRegions`——房间的区域 = 它**已摆家具的格**所在的区域。
- **走廊(hallway)** = 没有任何家具的区域（`hallwayRegions`）。走廊是连接大门和各房间门的通道。

## §6 门 / 大门 / 窗

- **房间门**（`doors[edgeKey] = roomSlot`）：每个房间**恰好一道门**（例外：若大门的室内侧正好落在该房间区域，房间可不另设门，兼作门厅 lobby）。校验（`analyseAccessibility.doorIssues`）：
  - 门必须在**自己房间区域的边界**上；
  - 门两侧必须是**不同区域**；
  - 若场景要求走廊（默认要求）：门的**非自己一侧**必须是走廊 / lobby / 室外，**不能直接通向另一个房间**。
- **大门**（`frontDoorEdge`，唯一）：必须在**外墙**上（两侧一边室内一边室外）。它把 **OUTSIDE → 室内侧区域**（走廊/门厅）连起来。
- **窗**（`windows[edgeKey]`）：**只能开在外墙**上。纯装饰，只在场景奖励分（如"朝某向的窗""透过窗望见树/湖"）里起作用。

## §7 可达性（连通模型，`analyseAccessibility`）

把区域当节点，建图：
- 每道**门**连接其两侧的区域（室外侧记为 `OUTSIDE = -1`）。
- **大门**连接 `OUTSIDE` ↔ 其室内侧区域。
- 从 `OUTSIDE` **BFS** → 得到所有"从室外可达"的区域 `outsideAccessible`。
- **房间可达**(`isRoomAccessible`) ⟺ 它的区域在 `outsideAccessible` 里。
- **自由空间可达**(`analyseOpenSpaceAccessibility`)：每件家具的 open_spaces 必须能从**它房间的门**走到（连通、可走）。不满足 → 该家具不计分。
- **孤立区域(orphan)**（`findOrphanRegions`）：没家具、又从室外走不到的"死口袋"。仅当**所有房间封顶 + 大门已放**后才判定。

## §8 计分（`computeScore`，精确）

**一件家具"计分有效"**当且仅当三条全满足：
1. 它的 open_spaces 从房间门可达（§7）；
2. 它的 `wall_edges` 都有墙背书（§4）；
3. 它的**房间从室外可达**（§7）。

总分 = **占用格分 − 空房罚分 + 奖励分**：
- **占用格分**：每个"计分有效"家具的**占用格数** × +1（`squaresPerPiece` = 在界内的 shape 格数）。无效家具的格子不计（计入 `droppedSquares`）。
- **自由空间**：计 0。
- **空房罚分**：每个**一件家具都没画**的房间 −3。
- **奖励分**：按场景 `bonus_points`，逐条用对应 evaluator 判定（布尔得分，或 `count` 逐个相乘）。
- `total = countedSquares + emptyRoomPenalty + bonusTotal`。

> 注：规则书说地毯(#33)不计占用分；`squaresPerPiece` 目前按 shape 格数统计——若地毯 option 的 shape 非空需在此排除（**待核**）。

## §9 万能牌（joker，每人每局一次）

绿色标记盘首次出现时可用一次：**换同号另一变体** 或 **把该家具镜像翻转**。用过即不可再镜像。

## §10 一局完整流程（原版）

1. 选任务，抄预绘元素。
2. 逐房间：翻当前房间的家具卡 → 选 option → 全员同时画（可旋转、不可镜像除非用万能牌）→ 一个房间所有卡画完 → **封墙 + 每房一道门** → 进下一房间。
3. 全部房间封完 → 画**大门**、连**走廊**。
4. 结算：占用格 +1、空房 −3、奖励分；最高分胜。

## §11 Cocos 简化版差异（我们故意改的）

- **顺序出卡 + 二选一**：选房间后家具卡**逐张**出现，每卡展示**两个 option**，玩家二选一建造（原版是全摊开、可任选、全员同时画）。
- **一次只建一个房间**：家具阶段 → 造墙阶段（先砌墙 → 再门/窗）→ 完成房间 → 自动进下一房间。
- **按房间锁墙**：房间封顶后其墙**锁定**（恒白、不可删、新房间的门/窗不能落在其上）。当前房间未封死的墙显示**红色**，封死/`validateWallTopology` 通过后变白。
- **门/窗仅当前房间**：门只能开在当前房间的（未锁定）墙上；窗只能开在当前房间区域的外墙上。
- **大门阶段**：所有房间封完后进入**大门阶段**（玩家点外墙放大门），结算按钮以 §7「全连通」为门槛（**待实现**，本轮正要做）。
- **镜像 = 万能牌**：保留每局一次。
- **视觉**：海军蓝蓝图风、白线稿家具（卡图反色）、行列标签、黄门蓝窗外开符号。
- **美术**：无法直接复用网页的 SVG/CSS，改用反色 PNG + Graphics 重绘。
