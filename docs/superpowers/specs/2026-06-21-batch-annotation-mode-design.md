# 标注工具:批量打标模式设计

日期:2026-06-21
文件:`tools/sprite-annotator/index.html`(单文件,纯前端)

## 目标
让用户一次框选多个格子,剔除非矩形家具多出来的小格,并用同一基础名(如「床」)自动批量命名为 `床1 床2 … 床N`,顺序「先横再纵」。

## 状态与模式
- 新增批量选区 `batchSel`:一组 `"col,row"` 键的 `Set`,代表「待命名」的格子。
- `batchSel` 非空 = 批量模式;为空 = 现有单格模式。
- 无独立开关按钮,Shift+拖拽自然进入。
- 新增拖拽状态:`boxDragging`(bool)、`boxStart`({col,row} 锚点)、`boxCur`({col,row} 当前),用于绘制矩形预览。

## 交互流程
1. **Shift + 左键拖拽**:画矩形预览;松手把矩形内所有格子并入 `batchSel`(并集,可多次 Shift 拖拽追加不同矩形以拼非矩形)。
2. 批量模式下**普通左键单击**某格 = 在 `batchSel` 中切换该格(剔除/加回)。
   - 此时左键临时改变含义:不再走「选中单格 + 填标签」逻辑。用户已确认接受。
3. 右键/中键/空格平移、滚轮缩放照常,不受影响。
4. 右侧出现批量面板(仅 `batchSel` 非空时显示):显示 `已选 N 格`、基础名输入框、`批量打标` 按钮、`取消` 按钮。
5. 点 `批量打标`(或在基础名输入框按回车)→ 写入标签、清空 `batchSel`、退出批量模式。
6. **Esc** = 放弃当前选区,不命名。

## 编号规则
对 `batchSel` 中实际选中的格子:
1. 取包围盒 `minCol..maxCol`、`minRow..maxRow`。
2. 按 `row` 从小到大、每行 `col` 从小到大扫描(先横再纵)。
3. 跳过未选中的格,对选中的格依次 `index = 1,2,3…`。
4. 标签 = `${base}${index}`。

示例:床 3×2 剔除 1 格 → 剩 5 格 → `床1 床2 床3 床4 床5`,编号连续不留洞。

目标格若已有标签 → 直接覆盖(`ann.set` 覆盖即可)。
基础名为空 → 不执行,给出提示(不写入)。

## 渲染
- `batchSel` 格子高亮:青蓝半透明填充(如 `rgba(120,200,255,.30)`)+ 青蓝描边,与现有打标色(琥珀)/冲突色(红)区分。
- Shift 拖拽中:在锚点→当前格的矩形上画虚线预览框。
- 批量模式下 `#hint` 文案切换为批量操作提示(单击切换 / 基础名 + 批量打标 / Esc 取消)。

## 复用与边界
- 命名生成的 `床1..床5` 各不相同,不触发现有冲突标红;若两件家具都用「床」当基础名才会冲突,交给现有冲突系统照常标红。
- 复用现有 `ann` Map 与 `refreshList()` / `render()` / `save()` 链路;批量打标本质 = 对 Map 批量 `set` 后走一次 `refreshList()`。
- 不改导出/裁切逻辑(导出仍读 `ann`)。
- 单格选区 → `床1`(始终带编号,保持一致)。

## 验证
- 框选 3×2,直接批量打标「床」→ 得到 `床1..床6`,顺序先横再纵。
- 框选 3×2,点掉 1 格,再批量打标 → 得到 `床1..床5`,连续无洞。
- 多次 Shift 拖拽追加不相邻区域 → 都进入选区,按全局包围盒先横再纵编号。
- Esc 清空选区,回到单格模式,原有点击打标功能不受影响。
- 覆盖:对已有标签的格批量打标 → 被新名覆盖。
